### ⚠ BREAKING CHANGES

* load/save annotation gutter width and fold state
* split up global annotation view into smaller, more understandable chunks
* add the ability to add/edit/remove comments from global annotations view ([#17](https://github.com/cajias/obsidian-criticmarkup/issues/17))
* merge live preview renderers into single extension for improved performance
* rename "node" to "range" to better reflect criticmarkup semantics
* comment gutter performance improvements
* nodes kept in statefield instead of calculate ad-hoc from tree, every node maintains its own text
* plugin id change
* finish rewriting deletion logic
* finish regular cursor movement in suggestion mode
